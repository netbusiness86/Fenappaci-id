PROJET : FENAPPACI — IDENTIFICATION NATIONALE DES PRODUCTEURS AGRICOLES

Tu vas créer une application web/PWA professionnelle appelée FENAPPACI, destinée à l'identification et au suivi des producteurs agricoles en Côte d'Ivoire.

1. OBJECTIF DU PROJET

L'application doit permettre aux agents de terrain de la FENAPPACI d'identifier rapidement les paysans/producteurs agricoles, d'enregistrer leurs informations, leurs exploitations, leurs parcelles et leurs productions.

L'application doit être conçue dès le départ pour pouvoir évoluer ultérieurement vers :

- gestion des producteurs ;
- gestion des coopératives ;
- géolocalisation des exploitations ;
- production agricole ;
- collecte ;
- commercialisation ;
- contrats ;
- financement ;
- intrants ;
- statistiques nationales ;
- carte interactive des producteurs ;
- carte numérique FENAPPACI avec QR Code.

NE DÉVELOPPE PAS ENCORE ces modules avancés. Prépare seulement une architecture permettant de les ajouter proprement plus tard.

---

2. TYPE D'APPLICATION

Créer une PWA responsive, prioritairement optimisée pour les téléphones Android utilisés par les agents de terrain.

Elle doit également fonctionner correctement sur :

- smartphones ;
- tablettes ;
- ordinateurs.

Prévoir dès le départ une architecture compatible avec le fonctionnement hors connexion, même si la synchronisation offline complète sera développée dans une étape ultérieure.

---

Nom :

FENAPPACI

Slogan :

« La recherche de la qualité, notre affaire. »

Utiliser une architecture moderne et maintenable.

Prévoir :

- React
- TypeScript

Backend :

- Node.js
- API REST structurée

Base de données :

- PostgreSQL
- ORM moderne, de préférence Prisma

- système sécurisé de connexion

Stockage :

- architecture permettant de stocker ultérieurement les photos et documents

Cartographie :

QR Code :

- architecture permettant de générer un QR Code unique pour chaque producteur

8. RÈGLE IMPORTANTE SUR L'ENREGISTREMENT

Il n'existe PAS de système de validation manuelle dans cette première version.

Lorsque toutes les informations obligatoires sont complètes et que l'agent termine l'enregistrement :

Le système doit automatiquement créer le producteur.

Afficher :

✅ PRODUCTEUR FENAPPACI ENREGISTRÉ

Générer automatiquement :

- numéro unique FENAPPACI ;
- date et heure ;
- agent ayant enregistré le producteur ;
- QR Code unique.

Exemple :

FEN-CI-2026-000001

Le numéro doit être généré automatiquement par le système et ne doit jamais être saisi manuellement par l'agent.

---

9. PHOTOS

Les photos supplémentaires de terrain sont FACULTATIVES.

Ne jamais empêcher l'enregistrement d'un producteur parce qu'une photo d'exploitation, de parcelle ou de stock n'a pas été ajoutée.

Préparer simplement la structure permettant de les ajouter ultérieurement.
